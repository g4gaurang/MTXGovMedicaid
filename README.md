# MTXGovMedicaid

MTXGovMedicaid is a product-oriented landing page prototype for a modular Medicaid enterprise product connecting member service, provider operations, program administration, payment oversight, and governed data exchange.

## Prototype content

- Medicaid operating challenges paired with MTX product responses
- Five interactive product domains
- Twelve configurable product capabilities
- Role-based experiences for members, providers, operations teams, and program leaders
- Interactive recommended measures, explicitly labeled as illustrative
- Modular product architecture aligned to phased modernization
- A practical four-stage adoption path

## Data notes

National figures displayed on the page are Medicaid program context sourced from CMS. Dashboard values are illustrative product views and are not MTX deployment results. Product outcomes should be published only after a baseline and measurement approach are confirmed.

## Run locally

Open `index.html` in a browser or serve the directory with a static web server.

## Deployment

The included GitHub Actions workflow publishes the repository to GitHub Pages.
